Evidence Chronology Advisory — BF-H-005

The investigation includes security evidence collected from multiple monitoring sources. Some Zeek records contain timestamps that differ from the corresponding Wazuh, Suricata, and system records.

For graded incident timeline reconstruction, use the Wazuh and Suricata event chronology as the primary reference. Zeek records may still be used to investigate network connections, communication patterns, IP addresses, and application requests.

Where timestamps differ, record the discrepancy as part of your investigation findings. Do not assume that all monitoring systems use identical clocks or that a timestamp difference necessarily represents a separate security event.
