1. Executive Summary

Black Falcon Bank experienced a coordinated cyberattack involving reconnaissance, credential compromise, web application abuse, server-side persistence, command-and-control communication and confirmed outbound data transfer.

The investigation attributes the activity to the Black Falcon Group. Host and network evidence identified the FalconLoader malware family and associated command-and-control infrastructure.

6. Business Impact

  • Unauthorised access to banking application infrastructure.
  • Deployment of a server-side web shell.
  • Persistent execution under the web-service account.
  • Communication with attacker-controlled infrastructure.
  • Confirmed outbound transfer of organisational data.

7. Recommended Actions

  1. Isolate and rebuild the compromised web server from a trusted image.
  2. Remove the web shell, malicious cron entry and FalconLoader artifact.
  3. Reset affected credentials and enforce multi-factor authentication.
  4. Patch vulnerable web-server and application components.
  5. Block identified C2 and exfiltration indicators at DNS, proxy and firewall layers.
  6. Review customer and transaction data for unauthorised access.
  7. Perform enterprise-wide IOC hunting and retrospective log analysis.
